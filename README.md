# 📚 NOTES — Decentralized Notes Sharing Platform

> **Share. Verify. Learn.**
> A blockchain-powered notes sharing platform where students can securely upload, verify, and discover academic resources.

🌐 **Live Demo:** https://notes.swarnavo.co.in

---

## 🚀 Overview

NOTES is a decentralized platform designed to make academic note sharing secure, transparent, and tamper-proof. Instead of relying on centralized storage alone, every uploaded document is cryptographically verified and recorded on the blockchain.

Each file is hashed using **SHA-256**, stored on **IPFS**, and its hash is registered on the **Polygon Amoy Testnet**. This ensures that anyone can verify whether a document has been modified after publication.

## ⚙️ How It Works

1. User connects their MetaMask wallet.
2. A PDF is uploaded to the platform.
3. The file is stored on IPFS.
4. A SHA-256 hash of the document is generated.
5. The hash is recorded on the Polygon blockchain through a smart contract.
6. Anyone can verify the document's authenticity by comparing the file hash with the on-chain record.

---

## 🎯 Problem Statement

Students often share notes through messaging apps or cloud storage, where documents can be modified without any way to verify their authenticity.

There is no trusted method to prove that a shared note is the original version uploaded by the author.

---

## 💡 Solution

NOTES solves this problem by combining decentralized storage with blockchain verification. Every uploaded document receives a unique cryptographic fingerprint stored on-chain, allowing anyone to instantly verify that the file has not been altered.
